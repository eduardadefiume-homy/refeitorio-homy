# ADR-0005 - Documentação no Git e documentação interna formal

Data: 18/06/2026  
Status: Aprovado

## Contexto

O projeto precisa ser mantido por TI e também preservado como documentação institucional da Homy.

## Decisão

Manter documentação viva no Git em Markdown e documentação formal interna em Word/PDF por versão.

## Consequências

- O Git contém código completo, histórico e documentação técnica atualizada.
- A Homy mantém manuais formais para auditoria, operação e continuidade.
- Toda alteração relevante precisa indicar quais documentos foram impactados.
